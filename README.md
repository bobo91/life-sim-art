# Life Sim Art
Codex-owned, AI-first procedural 3D asset production for [Life Sim Game](https://github.com/bobo91/life-sim-game).
Start with AGENTS.md, docs/ART_DIRECTION.md, docs/ART_CONTRACT.md, and GitHub issues ART-001 through ART-004.
Pipeline goal: Blender Python -> validate geometry -> export GLB -> render previews -> manifest/checksums -> versioned release -> Unity import.
No final third-party meshes or asset packs.

See [the headless pipeline guide](docs/PIPELINE.md) for pinned tools, build/validation
commands, reproducibility guarantees, output schema and Unity compatibility limits.
